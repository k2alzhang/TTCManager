# MC 服务器管理面板 — 静态界面设计（短版）

日期：2026-11-12
状态：已获用户确认

## 意图
按 `界面设计要求.md` 画出 MC 服务器管理面板的静态前端界面，先不接真实数据、不做后端。用户后续会往 md 里逐步加需求，界面再迭代。

## 目标
- 两个页面：服务器列表、管理后台
- 后台首页按 md 布局：顶部名字+右侧控制按钮；左侧导航（首页/文件管理/模组插件/玩家列表）；中间日志终端（约500px宽、全高）+ 下方命令输入框（约20px高）
- 首页监控卡片：内存/CPU/网络上传下载/JDK/玩家数/TPS，卡片内显示占用 + 曲线图（图不超出卡片、有显示动画），加服务器属性（核心版本、游戏版本）
- 用模拟数据让界面"活"起来，曲线用 Canvas 自绘，无外部依赖

## 非目标 / 反目标
- 不做真实数据请求、不做后端 API、不做登录/鉴权
- 文件管理、模组插件、玩家列表三页先只做占位页

## 约束
- 纯静态：HTML + CSS + 原生 JS，零构建、零依赖
- 手机（Termux）上直接打开即可预览

## 方案（Approaches）
- 选定：纯静态 HTML（用户拍板）
- 放弃：React + Vite / Vue + Vite（引入构建流程，迭代慢，不贴合"先画界面"节奏）

## 结构决策（用户确认）
- 拆两个页面文件：`index.html`（服务器列表）+ `admin.html`（管理后台）
- 文件管理/模组插件/玩家列表：本步做占位页，导航可切换，内容后续再画

## 留给实施者的决策
- 模拟数据数值、配色、具体样式细节由实施者定，遵循 md 中尺寸/布局约束
